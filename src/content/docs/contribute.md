Cadenza is built in the open so that anyone can improve it. You do not need to write Swift: documentation, model evaluations
on your own voice and bug reports are real contributions.

| You want to… | Start here |
|---|---|
| Report a bug | The [Bug report form](https://github.com/DragonKingIO/Cadenza-voice/issues/new/choose). Do not attach recordings, transcripts or unredacted logs. |
| Suggest a feature | The Feature request form. For large changes, discuss first. |
| Propose a model or a cloud service | The Model request or Cloud provider forms. |
| Offer a translation | The Add a language form first: a third language still needs some code work. |
| Improve the docs | Edit a page and open a pull request. |
| Write code | [Developing Cadenza](../contribute/developing/), then the [contributing guide](../contribute/contributing/). |
| Report a security problem | Privately, as described in the [security policy](../contribute/security/). |

## The one rule that matters most

Cadenza promises that nothing leaves the Mac unless the user turns it on. Every change is reviewed against that promise. The
[contributing guide](../contribute/contributing/) spells out the privacy contract.

Please follow the [code of conduct](../contribute/code-of-conduct/). Reviews are done by volunteers, so be patient and kind.

## This website

The site lives in its own repository, [cadenza-site](https://github.com/DragonKingIO/cadenza-site). The technical pages (local
API, accuracy, models, privacy notice, contributing guides) are generated from the application repository, so fix those at the
source.
