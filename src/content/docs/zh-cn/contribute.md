随言公开开发，任何人都可以让它变得更好。你不需要会写 Swift：文档、用自己声音做的模型评测、问题反馈，都是真正的贡献。

| 你想… | 从这里开始 |
|---|---|
| 反馈问题 | [问题反馈表单](https://github.com/DragonKingIO/Cadenza-voice/issues/new/choose)。请不要附上录音、识别文字或没处理过的日志。 |
| 提功能建议 | 功能建议表单；较大的改动请先讨论。 |
| 建议某个模型或云端服务 | 模型建议、云端服务适配表单。 |
| 提供翻译 | 先用“添加语言”表单：加第三种语言目前还需要改一些代码。 |
| 改进文档 | 编辑一个页面并提交 Pull Request。 |
| 写代码 | 先读[开发指南](../contribute/developing/)（英文），再读[贡献指南](../contribute/contributing/)（英文）。 |
| 报告安全问题 | 按[安全政策](../contribute/security/)私下报告。 |

## 最重要的一条

随言承诺：除非用户主动开启，否则任何东西都不会离开这台 Mac。每个改动都按这条承诺审查，[贡献指南](../contribute/contributing/)里写明了隐私约定。

请遵守[行为准则](../contribute/code-of-conduct/)。评审由志愿者完成，请保持耐心和善意。

## 这个网站

网站在单独的仓库 [cadenza-site](https://github.com/DragonKingIO/cadenza-site) 里。技术页面（本地接口、准确度、模型、隐私说明、贡献指南）是从应用仓库生成的，要改请改源文件。
