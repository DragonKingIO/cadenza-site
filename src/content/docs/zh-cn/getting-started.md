title: 快速开始
description: 安装随言，选择识别方式，说出第一句话。
---

随言把你说的话变成文字，写到光标所在的位置。按住快捷键，说话，松开。

## 你需要

- Apple 芯片或 Intel 的 Mac，运行 **macOS 14 或更高版本**。
- 推荐的本地模型大约需要 200 MB 空间（你需要时由应用下载）。
- 一个麦克风。

## 1. 安装

从 GitHub Releases [下载 .dmg](../download/)，打开后把随言拖进“应用程序”。应用没有公证，macOS 第一次会拦截：到 **系统设置 → 隐私与安全性**，点 **仍要打开**。也可以[从源码构建](../download/#source)，几分钟即可。

## 2. 首次运行

第一次打开会出现一个简短的向导：说明隐私承诺、带你完成权限授权，并让你选择识别方式。建议选**本地模型**：识别在你的 Mac 上完成，不上传任何内容。推荐 **SenseVoice**，应用会帮你下载。

## 3. 允许权限

| 权限 | 用途 |
|---|---|
| 麦克风 | 录音时听到你的声音 |
| 辅助功能 | 找到输入框并写入识别结果 |
| 输入监控 | 检测全局快捷键 |
| 语音识别 | 仅在选择 Apple 自带识别时需要 |

“设置 → 隐私”里能看到每项权限的状态。如果快捷键页面提示某项权限“已开启但未生效”，见[快捷键与权限](../shortcuts-and-permissions/)。

## 4. 开始说话

1. 点进任意文本输入框。
2. **按住快捷键**（默认是左 Option），说话，然后松开。
3. 文字会写到光标处；写不进去时，应用会保留文字，方便你复制。

按 **Esc** 可取消录音。可以在“快捷键”页修改快捷键，或改成“点一下开始、再点一下结束”。
