## 快捷键

默认是**按住左 Option**，说话，松开。松手时文字被写入。按 **Esc** 取消。

在**快捷键**页你可以：

- 修改快捷键：点**更换…**，按下想用的键或组合；
- 改成“点一下开始、再点一下结束”，并设置它自己的快捷键；
- 关闭快捷键。关闭后仍可从菜单栏图标开始录音。

单个修饰键（左 Option 或右 Option）只要单独按下，就可以作按住快捷键。如果同时按了别的键，这次录音会被取消，所以平时的 Option 组合键不受影响。

## 该选哪个键？

左 Option 只是默认值，并不是 macOS 的标准。macOS 自带听写默认是连按两下 Globe（Fn）键来启动。随言使用单个修饰键，是因为它们能可靠地检测到。

目前**左 Option 和右 Option 是随言仅有支持的单键快捷键**，Fn 键本身也不支持。Command、Shift、Control 是特意不放开的：它们平时总在别的快捷键里被按下，单独按住就会误触发录音。Option 平时还用来输入特殊字符和做快捷键。同时按了别的键时随言会取消这次录音，但按下的瞬间录音已经开始了一下。

如果 Option 碍事，可以在“快捷键”页录制别的快捷键：一个键加至少两个修饰键（其中含 Control 或 Command），或者一个功能键。

## 权限

| 权限 | 为什么需要 |
|---|---|
| **麦克风** | 录音时听到你 |
| **辅助功能** | 找到当前输入框并写入结果 |
| **输入监控** | 在别的应用在前台时也能检测到全局快捷键 |
| **语音识别** | 仅在使用 Apple 自带识别时需要 |

**设置 → 隐私**里列出每项权限和状态，只有仍需要处理的权限才会出现按钮。

### “已开启但未生效”

macOS 有时会一直显示权限为已允许，但应用其实已经用不了。比如你把开关关掉再打开、或者应用被重新构建之后。随言会检查并提示。处理方法：

1. 打开 系统设置 → 隐私与安全性 → 输入监控（或辅助功能）。
2. 把随言关掉再打开，或者用 **−** 删掉后重新添加。
3. 退出并重新打开随言。

权限变化和 Mac 从睡眠唤醒后，快捷键监听也会自动重建。

## 键盘与键位映射

快捷键跟随 macOS 报告的实体按键。如果没有反应：

- **PC 键盘**上，Alt 和 Windows 键可能与 Option 和 Command 互换了。打开 设置 → 快捷键，点**更换…**，直接按你实际想用的键。
- 检查 系统设置 → 键盘 → 键盘快捷键 → **修饰键**，以及任何改键工具里有没有改动 Option 或 Command 的规则。
- 远程控制或虚拟键盘软件可能让 macOS 以为某个普通键一直被按着。随言会忽略它从没见过被按下的键，所以不应该挡住快捷键；如果还是挡住了，请[提交问题](https://github.com/DragonKingIO/Cadenza-voice/issues)。
